# 本机操作记录导出（170）

2026-10-13。源自完整目标的「返回实际结果、留存可回顾的本地研究记录」：167–169已持久保存原生请求/意图/回执，但手机上难以直接取出这些记录检查。本批增加设置→原生操作→本机操作记录→导出本机操作记录，使用原生文件保存面板，由用户选择保存位置。本批已随0.65.13/170双端TestFlight发布，ASC实际VALID、IN_BETA_TESTING及中文说明均已核验，见[evidence/testflight-170.json](evidence/testflight-170.json)。设备是否安装与真实文件面板保存/取消仍未核验，不以发布当作手机已得到更新。

## 范围与证据边界

只读取固定三份本机文件：native-remote-v1.json（请求、原始参数/结果、失败/重试、同commandId/attemptId及权限版本）；native-actions-v1.json（改前/提议/实际回执）；task-commands-v1.json（当前共享快照、待提交命令和缓存回执）。不读取连接配置、凭据、SwiftData数据库、照片、其他设备或云端独有档案；无网络客户端、无MCP写入入口、无授权改变与操作重放，不自动创建导出文件。

导出格式schemaVersion=1，带App版本/build、导出时间、每份读取时间、源修改时间、源字节数及原始SHA256，完整保留可读JSON的未知字段。每文件原子写入保证读到一份字节快照，三份文件不是同一事务，因此atomicAcrossFiles=false。源哈希描述原始字节，导出内容经过遮蔽，不能以它验证字节完全相同。JSON可读不等于执行日志语义验证，设备保存、另一端显示、闹钟响铃、人看到均不可由导出推断。

来源逐份列明：snapshot_included、not_present、unsupported_file_type、too_large_original_retained、unreadable_json_original_retained或read_failed_original_retained。单文件缺失/坏掉不伪造空操作，不阻挡其他文件保存。大文件和损坏JSON只给状态与可取得的定位/哈希，不夹带未经字段检查的原始损坏文本；源文件保留，可本地进一步诊断。符号链接不跟随，避免扩大读取范围。读取上限16/4/4MiB，后台任务解析，避免主线程处理大日志。

凭据字段、Bearer/API key/私钥标记、常见URL凭据参数和模型私有思维字段会遮蔽；保留授权状态、权限版本及数值token费用指标。连接和凭据文件根本不进入来源名单。任意自由文本中无法识别的秘密不保证自动发现；导出仍可能包含日记正文、事项与个人请求，只由用户自行保存，不自动发给Dots或新服务。

本批不做自动清理、原件删除或日志恢复，也不调整现有容量/保留合同；不称完整数据备份。研究Recorder既有365天/2GiB设置与版本2导出继续，本机日志可配置容量/保留UI仍为后续增量，不用扩建平台阻挡试用。

## 产品哲学与停止

对照CLAUDE五原则、行为文档§2/§5：只在本人主动点导出时读取，不新增写日志义务、通知或历史生活评分；这是当前系统操作可核查证据，不是审计用户过去。原生文件面板和明确缺口支持掌控感，失败不静默。无新增授权范围或新资料服务。导出由用户选择的文件位置决定保存；若选择同步目录，按该目录既有同步行为运行，BC不替用户选择或上传。

取消文件面板即不保存本次文件；原记录、计时和授权照旧。源码回滚仅移除导出入口与实现，原始日志和169协议仍保留；导出文件不具备导入/执行能力。
