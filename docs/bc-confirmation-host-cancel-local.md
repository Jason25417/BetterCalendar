## 实际修改

表单只用短标题“请本人确认：开始计时。”，完整标题、原话、目标设备、原版本、日期、补记起点、期限和请求编号放在确认项的标准 description 内，原文不截断、不用 HTML，默认仍 false。这是减少超长标题的安全改善；宿主拥有布局，不能据此声称窄列/空白根因已经解决。Boolean description 是标准支持的字段。[Schema 说明](https://modelcontextprotocol.io/specification/2026-07-28/client/elicitation)
