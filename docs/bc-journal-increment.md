# 日记接入：本地统一入口先行

2026-10-13。本批保持个人实验原型边界；代码接在AppContainer现有SwiftData与NativeActionJournal上，不改@Model、不迁移旧史，不新建资料服务。**本批日记代码尚未包含在已经发布的167包，也没有开放给Dots。** 不为一个未接通的内部入口再单独发布TestFlight。

## 已实施、已测试

`NativeJournalAccessing`独立于事项权限；读取必须显式允许，写入必须是明确用户请求。当前信任边界是App内的受控调用者，bool不作为未来MCP授权参数。`SwiftDataNativeJournal`提供完整保存文本/格式/心情/标签/照片引用/创建与修改时间/回收站信息、日期半开时间窗与关键词检索。读取不会创建今日空日记、触发通知或改变计时。返回检索时刻、来源、派生逻辑日的时区和4点日界线、覆盖缺口。

分页绑定条件与全文快照哈希，直接外部改正文而不改modifiedAt也会使旧游标失效；不能混合新旧版本宣称读完。数量和字节共同限制页大小；大于当前单条32KiB完整读取上限时报明确错误，不截断后称完整。照片返回引用，未读取图片二进制或确认跨端同步，不能声称看过照片。

新增/修改Markdown正文、心情与标签；同逻辑日已有未删除日记时不另建，刷新后修改原条。其他正文格式可读取原文但不以Markdown覆盖；照片、日期、格式和保留字段不由文字补丁修改。只接受明确用户来源，不写代理推断。先持久化before/proposed完整意图，再保存SwiftData，再保存回执；失败可见。更新需全文revision，直接修改会冲突。原文保留在受控的native-actions-v1.json（现有原子私有文件，4MiB/2000条容量，满时保留原件并拒绝新写入）。恢复原文是再次读取当前版本并确认新的文字更新，不自动覆盖后续文字；删除/恢复仍只沿用现有原生回收站，未新增代理删除能力。

同commandId同内容返回原回执；保存成功但回执丢失，重启后核对完整结果恢复回执，不重复创建。后来改过文字时保持未知，不覆盖。损坏/篡改的未决快照不重放，保存失败不会回滚其他尚未保存的编辑。

已验证：Mac全量305/305，失败0、跳过0；其中日记9项。iOS Simulator编译成功。使用隔离内存库/临时文件与fixture照片，不创建用户真实日记或反馈。涵盖原文恢复且保留照片、独立读权限与不创建、固定分页与直接改库、时间窗/回收站/照片覆盖、版本冲突/非法字段/未知格式、落盘失败和响应丢失/重启、同日并发与后来文字、字节上限、私有文件保存、亚毫秒日期与篡改意图。

## 下一小批，尚未实施

1. 在既有指定设备队列中加入日记读取与create/update，新增单独的journal.read与journal.create/update权限，默认不随事项权限开放。
2. 读取从指定设备取当前保存版本，明确设备在线等待、范围、分页与照片未取；MCP只用统一逻辑入口，不让代理分别向多端重复写入。选择请求回执式读取或已有临时目录发布时，必须写清原文流向及授权，不静默镜像全部日记。
3. 新增/修改文字继续使用Dots具体确认卡片；模型声称同意无效。修改先读取原条和revision。正文里的指令只当资料。
4. 把真实请求、原文定位、检索时间、设备实际结果接入既有本地研究档案。用一条用户真正需要的日记操作验证，再决定是否发下一次TestFlight。

未验证：真实用户日记、Dots读取/确认、设备操作、照片实际内容读取、日记跨端时延。未读取图片不代表图片不存在，缺少反馈不代表认可。额外删除范围待Jason决定，当前按先读取/检索和明确确认后文字新增修改推进。

## 哲学审查与停止/回滚

不要求连续填写，不生成审计分数、任务债务或过去欠账。日记属于主观轨，助手观察或推断不能被写成用户感受。入口只为用户已有表达服务，与掌控感/成就感及代理不代权一致。研发错误仍可见，遵守开发期例外。

本批入口未接MCP或新增UI权限，停用即不调用它；不会产生后台采集。回滚代码时保留SwiftData、照片和动作原文，不能清空日志。旧版文件读取器不支持journal类型时应保留原件并报错，不篡改或删除回执；目前真实用户文件尚未写入journal类型，只有隔离测试写入。
