# 0.65.16 / 173：可点击的权限设置与一键开启

用户反馈：iPhone 的原生操作区域按钮误触，保存本机权限无法点击。未经手机屏幕诊断，不断言具体根因。代码存在两个问题：多个自动样式按钮嵌在 Form 同一父行；未连接时保存按钮直接禁用，没有理由。

本批将 Dots 权限独立为设置第一节，以直接 Form 行显示。大号一键按钮、分别选择、保存、撤回、刷新各有独立点击范围和明确按钮样式；原生操作与采集区域按钮也改为明确样式。保存后的实际权限、失败原因与期限可见，不把切换草稿开关说成已经生效。

一键开启仅覆盖本机现有对话能力：事项池四项、共享计时四项、日记读取/创建/修改三项；支持且系统允许时加单次闹钟设置/取消两项。先检查设备连接，再按需发起 AlarmKit 系统授权，再保存29天本机授权。系统拒绝闹钟会保存其他能力并明确部分成功；系统请求抛错或设备在期间改变则不保存；网络响应丢失保持未同步、可重试。不开启额外连接器、应用屏蔽、自动强提醒，具体写操作继续由本人在 Dots 确认。授权按钮不创建事项、计时、日记或闹钟。
